## 固定的更新语义

随机A采用标准Linear式Kaiming uniform（a=√5），B为零，seed1400；rank4、alpha4、alpha/r=1、dropout0。基座BF16，因子/梯度/Adam一二阶矩FP32，BF16 autocast前向。AdamW lr2e-4、betas(.9,.999)、eps1e-8、decay.01，梯度裁剪1。

一个expert的三个投影共六个A/B因子使用同一倍率，控制完整AdamW候选位移，包括其衰减。m=0保持参数不动，已学适配器仍参与前向；有梯度时Adam矩继续推进，grad=None按AdamW惯例跳过矩与衰减。m=1直接保留精确候选。倍率不是推理门控，也不会自动减少前后向计算。由于BA含双线性项，同时缩放A/B位移并非有效BA变化的严格线性缩放。

共享控制器采用expert编码、层/全局汇总、层base和最多两个不同expert修正，字母表{0,.25,.5,.75,1}；1024个位置不对应1024个agent。当前只测试结构化接口和确定性规则，未做高维随机探索。全层路由来自当前表示；参数冻结不意味着路由不变。记录样本/token覆盖、缓存年龄、观测耗时，不要求统计必须变化。

## 已完成的真实短测

[smoke_result.json](smoke_result.json)记录12次实际更新，包括机制分支、热身与两组三步测量：

- 开启零初始化LoRA后，整批logits与关闭适配器的同一基座逐位一致。
- 非零更新成立；m=0权重及已学前向不变，Adam矩与相同候选完整更新一致；混合倍率的最大位移误差1.46e-11。
- 全部原始权重的完整SHA256前后相同，不只检查requires_grad。
- 459,902,278-byte可恢复状态的权重、Adam矩、CPU/CUDA RNG精确恢复；保存1.381秒、读取恢复2.199秒。
- seq512当前microbatch1/2，加seq512回放microbatch1、累积1，实测每更新3.528/3.625秒；峰值分配15.44/17.20 GiB，峰值保留20.11 GiB。各仅3次，含Python/同步开销，不是稳定吞吐基准。
- 每层有效路由token673，63–64个expert获观察，缓存年龄0。带/不带统计的交替计时差出现负值，说明该小样本无法分辨增量开销；保留原值，不声称统计免费或加速。

这与v13两层短测的训练/回放配方不同，不能只拿.487秒对比推断LoRA提速或减速。原始执行版本在远端封存，归档时保留源码摘要与回执。
