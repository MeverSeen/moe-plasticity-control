# 不限定冲突形态的最小校准

检验在共同目标与预算内，有限时序安排或历史相关计划选择是否有可重复收益。**不把“低倍率失败、高倍率遗忘大”作为必要条件，也不把 oracle argmin 不恒定当作控制有效。**

正式实验已完成：六个设置、24 个校准历史；锁定 `target=0.08 / max_steps=100` 后用 64 个新历史确认。主要计划选择比较区间跨零。固定倍率特权选择有相对全局固定的收益，但全可行子集未胜过直接冻结，尚未验证动态反馈。见 [原始报告](results/main/analysis/实验报告.md) 和 [结果解读](结果解读.md)。

## 设计

- 保留现有 6-expert 非线性固定-router 环境、记忆、保护组、Adam 和五档倍率。原样复制 v4 的基础环境模块，暂不改变真实路由反馈。
- 六个目标/最大步数设置：`0.08/0.04/0.02 × 300/100`，包含 v4 的原配置。
- 每个设置 17 个有限计划：5 个固定倍率、6 个时间单次切换、6 个 B 进度单次切换。
- 新校准历史 24 个，选出一个配置及全局基线，锁定后在 64 个新确认历史评价。pilot 使用互斥历史。
- 每历史 2 个独立未来批次流；同一流所有方法配对。全局基线仅用校准流 0 选择；配置按跨未来诊断收益选择。
- 配置覆盖条件只要求有限计划逐历史可行覆盖≥80%、初始未达标比例≥50%，不要求同一固定计划处处可行。若无候选合格，保留原始参考配置做诊断并明确说明。
- 特权参考根据每个历史流 0 的完整终点结果选择计划，再用流 1 评价，不能用于在线决策。额外查询成本单列。
- 特权选择使用旧任务 test 遗忘标签；两流只改变未来 minibatch，复用同一历史与评估数据，不能称为旧评估数据上的独立验证。
- 在流 0 五个固定动作都可行的子集中单独报告流 1 的达标率与遗忘；流 1 失败不删除。

## 结论层级

固定计划 → 预设时间/进度安排 → 每历史特权选计划，是三种不同的能力。最后一种即使有收益，也可能仅需初始状态选择，不能自动证明实时反馈有增益或 RL 必要。当前 17 个计划也不是全部动态策略。

先比较达标率，再比较共同达标的原始遗忘，遗忘相同时才以工作量打破并列。统一阈值不保证端点 loss 严格相等，另报告紧端点匹配。`J` 仅为包含失败的诊断/配置选择代理，不能代替主要指标。

## 复现

从工程根目录运行：

```bash
python scripts/test_all.py
python scripts/run_experiment.py v5 --pilot --out runs/v5-pilot
python scripts/run_experiment.py v5 --out runs/v5-reproduction
```

输出目录必须是新的。`plan.json` 在校准前保存，`locked_protocol.json` 在首次创建确认历史前记录配置、计划与源码哈希。确认结果不得用于本轮调参。

查看正式确认后额外加入的敏感性分析明确标为事后分析，不改动锁定源码或选择：

```bash
python experiments/v5_calibration/diagnostics/selection_sensitivity.py \
  --run experiments/v5_calibration/results/main \
  --out runs/v5-posthoc-reproduction.json
```

动机与用户修正见 [校准目标说明](../../docs/calibration-objective-revision.md)，真实 MoE 路由改进已记入 [后续待办](../../docs/future-real-moe-routing.md)。
