# v5 结果解读：不限定冲突形态，也不提前认定动态控制有效

2026-09-16。原始自动报告与锁定协议未改动。本文件区分预先指定比较和查看确认结果后增加的敏感性检查。

## 用户修正成立

“低倍率学不够、高倍率遗忘大”不是必要条件。即使所有固定倍率都可行，不同历史也可能偏好不同倍率，更新顺序也可能改变达到同一新任务目标时的遗忘。需要验证的是相对足够强基线的可复测收益，而不是必须制造某一种冲突。

同样，所有倍率可行也不自动提供动态控制的理由。必须逐层区分：全局固定 → 根据初始状态选固定倍率 → 时间/进度调度 → 利用实时反馈重新决策。本轮特权参考知道完整未来结果，只能帮助探查计划选择空间。

## 正式结果

扫描 `target ∈ {0.08, 0.04, 0.02}`、最大步数 `{300, 100}`，每设置 17 个计划和两条配对未来流。24 个校准历史后锁定 `0.08/100`，64 个新历史用于确认。共 7,072 条正式轨迹；没有新增标签冲突、修改 router 或训练新控制器。

校准选出的固定基线是 `m=0.25`；时间基线为前 60 步 `m=0`、之后 `m=1`，提前达标就停止。进度计划的选择退化到固定 `m=0.25`。

1. **时序安排相对固定倍率尚未给出明确优势。** 两条流合计，固定基线达标率 96.09%，时间计划 94.53%。共同达标历史上的遗忘差为 −0.000839，95% CI [−0.001659, −0.000044]，但达标率较低，不能仅看遗忘宣称胜出。
2. **按历史选固定倍率的特权参考有局部正结果。** 用流 0 全部终点标签选一个倍率，独立流 1 评价：其达标率与全局固定均为 96.875%；旧任务遗忘均值从 0.007893 降至 0.006392，约 19.0%。配对差为 −0.001501，95% CI [−0.002437, −0.000767]。这是相对锁定全局固定的收益，不证明在线信息能预测该选择。
3. **更大的计划库没有带来稳定独立收益。** 特权按历史选 17 种计划，相对锁定时间计划，独立流 1 遗忘差 −0.000212，95% CI [−0.001279, 0.000817]；紧端点匹配和排除初始已达标/空保护组后仍跨零。有限样本上扩大候选库可能增加选择噪声，当前结果不能证明具体原因。

第 2、3 项使用流 1，不应把它们的达标率直接与第 1 项的两流汇总混用。特权参考用旧任务 **test** 遗忘标签选计划；两流共享任务和评估数据，只改变未来训练/回放批次，因此这里的复测只检验对批次随机性的稳健性，不是无特权的泛化结果。

## 事后敏感性：全可行子集为什么仍不能证明动态价值

预设分析发现，流 0 五档倍率全部可行的历史有 59 个，其中特权固定选择相对全局 `m=0.25` 的遗忘优势也成立。这个比较可能把“全局固定为少数难历史做的妥协”错当成全可行子集中的决策价值。因此在查看确认结果后，额外比较预先已运行过的 `m=0`，不重训、不换配置、不重新选择基线。

以下均为这 59 个历史的独立流 1；三种方法恰好都 100% 达标：

| 方法 | 旧任务遗忘 MSE |
|---|---:|
| 全局固定 `m=0.25` | 0.008075 |
| 按历史选择固定倍率的特权参考 | 0.006509 |
| 全局固定 `m=0` | **0.006325** |

特权参考相对 `m=0` 的遗忘差是 **+0.000184**，95% CI [−0.000180, +0.000646]；排除初始已达标/空保护组后的 42 个历史也没有显示优势。选择流 0 中，这 59 个历史有 45 个选择 `m=0`。相对 `m=0.25` 的收益因此不能证明全可行子集仍需要动态选择。

完整 64 个历史上，直接 `m=0` 达标率只有 92.19%，特权固定选择为 96.875%；这提示按历史判断何时需要放开更新值得研究，但还不能断言差异已稳健确立，更不能说实时反馈必要。按根历史 bootstrap 的达标率差区间为 [0, 10.94] 个百分点；全成功样本的经验区间也不代表未来失效率为零。

事后结果和重算程序：[数值](results/main/posthoc/selection_sensitivity.json)、[脚本](diagnostics/selection_sensitivity.py)。这是解释性敏感性检查，不应冒充新的预注册主要结果。

## 本轮决策

保留“可以不依赖特定冲突形态”的研究空间，但**不把本轮升级为动态反馈控制的正结果**。当前最接近正证据的是有限任务分布上的历史相关固定选择，下一步应先用在线可用信息检验能否复现它，并与初始条件选择、时间/进度规则比较。只有持续观测进一步改善闭环结果，才推进动态反馈主张；本轮没有支持直接扩大 RL 训练的证据。

更严格目标的部分校准配置出现较大样本内诊断收益，但没有达到预先设定的可行覆盖要求，未进入确认。不能事后改选它们，把校准集上的优势当作独立结论。新的实验必须使用新历史。

真实 MoE 的当前路由、历史路由和动态保护对象问题已记入 [后续待办](../../docs/future-real-moe-routing.md)，本轮保持固定路由实现。
