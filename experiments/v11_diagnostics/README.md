# v11：奖励可靠性、可控范围与温启动诊断

2026-09-18 执行协议。v10源代码、锁定协议、模型与结果保持不变。core.py/control.py从v10复制作为独立新版本基础，不回写旧实现。所有新增实验只读CIFAR训练文件；训练类0–59，开发类60–79；80–99及官方test不加载。新开发根属于已用开发类池上的新顺序/初始化，不能称新类别确认。

先复核v10归档，再做三项小规模实验。每阶段运行前保存具体配置、root/controller/action种子、源码hash、候选集合与预算。保留失败、固定完成基准、全表现矩阵、终点loss和实际成本；全部结果为探索性诊断，不设排序率53%等任意成功线。

1. **奖励可靠性**：8个新根（4训练、4开发）、每根学完1或2任务的完整起点，各6条配对真实分支（4随机结构动作、固定.25/1）。相同批次流与200旧样本预算。实际轨迹保存额外的特权研究评估：每任务完成时及终点的完整monitor250/eval500逐样本loss、标签、ID。这些只在诊断器中使用，不进入策略或正式reward，额外成本单列。比较原始正增量、同一有限样本的类别均衡估计、signed估计；另外对相同轨迹做随机/类别分层25张配对重复抽样，测选择代价、并列、差距、失败和覆盖。抽样重复及同根不同起点不是独立历史。部署候选仅允许200预算内的monitor分层保留（replay完全不改）或同样本reward估计改进，分开检验。
2. **可控范围**：上述多个完整起点，一步的候选方向统一由原始梯度/AdamW产生，比较全冻结、expert-only、所有非expert-only、共同更新，以及trunk-only/head-only。零倍率推进有梯度参数的矩；router始终冻结。再做每条自身重新计算梯度/矩的多步当前任务至同目标/预算，不能称固定方向分解。固定策略校准先在新8根扫描全部6个expert倍率，再对选出的expert基准扫描trunk倍率.25/.5/1、头倍率1；不强制沿用v10的.25。只有证据支持才增加trunk倍率动作，reward/memory/router其余保持不变。
3. **学习稳定性**：先在新开发根选固定幅度；保留从头v10结构策略、同接口概率温启动、固定基础＋随机稀疏修正，以及可比较PPO。验证随机分布与greedy，报告相同检查点的两种执行。至少4个controller seeds、8个开发根、12个独立训练根；最终确切轮数按短测成本写锁定协议，不用旧final测试选取。训练/选模/评价分离开发选择根与另组复测根（仍同开发类池）。增加样本量不自动视为机制修复。

## 记忆与权限

回放100＋监测100是learner、在线反馈和实际RL回报能访问的全部旧样本。逐样本完成基准保留；裁减只能删旧样本，不能重新取旧数据。开发研究评价与奖励可靠性特权探针另记权限/成本。类别分层monitor候选不改变replay样本或梯度；在固定动作下须实测learner参数/矩与矩阵完全相同，学习策略使用不同monitor时则同时改变可读反馈，不能当纯reward单因素。

## 后续已锁定学习协议

见 [learning_plan.json](learning_plan.json)。六组：原接口从头GRPO、同接口概率温启动GRPO、固定基准加稀疏修正GRPO、同修正接口PPO、仅改类别均衡奖励的修正GRPO、仅扩展trunk动作的修正GRPO。4个策略种子，每个12训练根×4分支，每轮1根，12轮；检查点0/6/12。8选择根与12复测根互不重合，均在开发类60–79。选择根分别为greedy/stochastic锁定检查点；复测运行初始、末轮以及选中检查点的并集，两种执行全部保留。每根使用一条配对动作随机流；它不是对随机策略期望的高精度估计。

每任务最多200更新，目标loss1.25，检查间隔10。训练总1152分支，开发选择1152完整历史，复测至多1728完整历史，另有288个前缀任务和60个固定基准历史。按72条实测固定轨迹1.969秒/条估计串行约2.24小时（未含优化器外层反传与并发竞争）；3个隔离CPU进程执行，实际耗时另报。每进程torch单线程，不共享策略随机状态。不得依据复测结果追加轮次或改选择。

校准选择expert=0。所有策略的第一个任务仍按v10固定expert=1学习；expert=0只适用于后续任务，前端、norm和当前/回放头仍可训练。共享scope探针可单独缩放头；实际trunk策略只控制front与norm，头始终1，router始终冻结。core中沿用的“shared always1”注释描述默认v10路径；v11显式倍率扩展以本协议及实际step代码为准。

温启动给基础模式与修正幅度各自.98概率，整份expert分配保持基础约.98⁴=.9224；稀疏修正固定每层基础分配、只抽一个修正对象与幅度，幅度保持基础概率.9，整份分配保持基础概率.9²=.81，每expert保持基础概率.975。trunk初始化给1倍率.98概率。三者探索分布不同，因此稀疏接口对照也包含探索强度/相关性变化，不能归因为纯参数化收益。训练GRPO/PPO保持原终局优势、两轮clip更新、lr3e-4与熵项，不另加监督损失或行为约束；温启动保持greedy不动不能单独证明已学会协调。
