F 是每个任务刚学会时的固定对角 loss 为基准，在序列末对旧任务 loss 增量取正部分的均值（j < k）；基准不会在后续任务后重置。k=0 没有旧任务，F 与 signed backward change 记为 null，不能与后续检查点比较。所有 cost 与失败历史都已纳入根级汇总。

## 配对比较

同一 root 内先平均 policy_seed。共同成功集合要求两种方法该 root 的所有 replica 都完成整段序列；all-root F 同时报告，避免因筛选成功历史而隐藏失败。bootstrap 区间只作探索性描述，不构成显著胜利或非劣结论。

本次为 pilot：结果仅用于检查流程、方差和效应量，不作显著胜利或非劣宣称。
