# v10 真实视觉多层 MoE 控制

开发日期：2026-09-18。独立于冻结的 v1–v7；两组动作 v8 已在 `codex/v8-allocation-ppo`（9e54f99）完成，不重复开发、不改变其负结果。v9 名称为其他确认实验保留。本版为 CIFAR-100 类不相交、四任务的资源受限 pilot，不是 La-MAML 复现，也不是完整 20×5。

## 接口与数据权限

- 小 CNN → 两层残差 MoE；每层 4 experts、top-2、宽48、expert隐藏96，84,044参数。router 权重冻结。dynamic 模式由可训练隐藏表示路由；fixed 模式由原始像素4×4池化及固定随机投影决定。前端、LayerNorm、当前/回放头始终倍率1，未参与loss的头不更新。
- AdamW 先更新矩并产生完整候选位移，再乘专家倍率；包括解耦衰减。零倍率不移动参数但有梯度时矩仍推进；grad=None 时参数、衰减及矩均跳过。无反向/前向节省主张。
- 倍率统一为 `{0,.25,.5,.75,1,1.5}`。结构策略每层采样基础倍率、一个专家对象、该对象的修正倍率；保存三者的条件联合概率。概率定义在包含潜变量的生成动作上，多个潜变量可能解码为同一最终倍率。因子化、两组和全局参照使用同字母表。两组按保留监测样本的历史使用率≥.5划分，在记忆更新的任务边界重算，段内固定；空组的随机变量也记录概率。此比较不是 v8 原来固定P及不对称15动作的复现。
- CIFAR-100 官方 Python 包，MD5 `eb9058c3a382ffc7106e4002c42a8d85`；[原始数据说明](https://cave.cs.toronto.edu/kriz/cifar.html)。按类别固定样本排列，500个训练图像/类分为 learner350、online50、独立开发评估100。官方test只在锁定后显式加载。
- 元训练类0–59，开发类60–79，最终类80–99。每根历史按seed抽样/排序4×5类，从随机初始化开始，无预训练。任务ID可见、多头分类。相同首任务统一倍率1，控制从第二任务开始。
- learner可访问的旧回放、在线监测和RL回报总预算200（回放/监测各半），每任务结束按 `floor(200/(2*已学任务数))` 等额保留；旧任务只截短已有前缀，不重新访问完整旧训练/监测数据。新任务样本不计旧记忆；完成后立即受限。回放每步轮换一个旧任务，batch16，loss权重.5；新batch32。
- 监测样本存储任务完成时的逐样本loss及路由；后续样本裁减保留原基准。评估矩阵保存全部任务（含尚未学习任务），完全不进入控制器/回报。矩阵对角线是固定完成基准。另报有符号变化、改善、本段损伤、最终绝对loss/accuracy。
- 观测包括历史/当前旧路由、当前新路由、使用率与gate mass、上个窗口候选位移RMS、上一倍率、覆盖、缺失、距上次覆盖的更新年龄、层位置；全局含loss、目标、进步、预算、任务位置、旧记忆遗忘。所有在线观测额外成本计入。

## 学习与评价

GRPO按同一完整模型、Adam、记忆、基准、数据流位置和观测历史克隆；每轮按当前行为策略重新产生真实轨迹。组内配对未来批次，策略随机流不同；数据按根/任务/局部步确定，提前停止不改变下一任务流。组内标准差下限.1；终局回报为 `-proxy_F/.1-3*失败任务数`。不含参考策略KL，需明确称本项目的GRPO适配。

PPO为同接口、同根历史/轨迹数/最大更新预算的Monte Carlo终局回报适配，额外critic。两者均两轮联合概率比clip(.2)更新，熵系数.002，学习率3e-4。实际消耗更新受提前停止影响，单独记录；不能把同预算上限说成实际工作量完全相同。

共享局部编码21→32→32；协调策略加入层内和全局均值。局部学习器屏蔽旧知识全局摘要，不读取其他expert动态摘要，保留任务进度。Progress消融当前旧路由、旧知识损伤及其可靠性特征，保留历史路由和充分的新任务进度。此消融是整个当前旧观测包，不只是单个loss标量。

开发比较固定倍率网格、时间规则、局部规则、协调规则和学习策略。开发真实闭环先按全序列成功率、再全根平均遗忘、再最终绝对loss选模，保留epoch0与中间点。最终测试前保存协议、源代码、选中模型的SHA256；独立命令检查锁定后才生成最终类历史。失败、初始已达标均保留。达标要求p_min=.9，非劣效界限5pp，仅作pilot描述，小样本不作确认性统计结论。

目标loss、预算等数值由校准后写入运行config/protocol，以实际运行文件为准。每个输出目录只创建一次。归档保留压缩JSON轨迹、协议、hash与报告，数据和权重在忽略的 `runs/` / `.cache/`，不纳入Git。

## 入口

```sh
mkdir -p .cache/datasets
curl -L --fail https://cave.cs.toronto.edu/kriz/cifar-100-python.tar.gz -o .cache/datasets/cifar-complete.tar.gz
python3 -m unittest discover -s experiments/v10_visual_control -p 'test_*.py' -v
python3 experiments/v10_visual_control/run.py calibrate --out runs/v10-calibration
python3 experiments/v10_visual_control/run.py train --config experiments/v10_visual_control/config.json --rounds 12 --group 4 --roots 8 --seeds 1001 1002 --out runs/v10-main
python3 experiments/v10_visual_control/run.py test --out runs/v10-main
```

训练轮数与独立历史覆盖另用同一配置的 `--rounds` / `--roots` 单项比较；每次独立输出，不能把分支数称作独立历史数。正式扩大前需看校准、学习行为、独立闭环结果和实测成本。

## 运行解释补充

- 2根/8根覆盖对照同时改变实际见过的训练类集合（见coverage_audit），因此是历史池覆盖扩展，不是固定同一组类别后只改变随机顺序的纯消融。两者候选类池均0–59，测试类仍完全隔离。
- 几组作业在同一CPU同时执行，墙钟保留但不能作为算法独占吞吐比较；learner更新数、样本处理数和分支数更可比。
- 单步探针发现局部非加性约5e-5–9e-5量级；仅说明所测方向存在交互，不证明协调或RL不可替代。非专家前端/Norm/头单独更新也可改变旧loss，专家倍率的保护范围有明确边界。

离线开发选模另访问隔离的每类100张评估图像，最终研究评价访问官方test；它们不进入动作或RL回报，额外样本处理成本单列。200不是连离线研究者评价权限也涵盖的全工程数据上限。
