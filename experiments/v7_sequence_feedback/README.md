# 连续学习中的段间与段内反馈

检验单次短学习可能不足以体现反馈价值的假设：同一个 learner 连续学习 B1、B2、B3，参数和 Adam 状态始终保留，再比较两种决策频率下旧知识反馈的增益。

**正式实验已完成。** 段间反馈提高达标率但增加遗忘；段内反馈在共同达标历史上降低 A 遗忘约 13.8%，但达标率略低、两项主要比较的校正敏感性区间跨零。是需要复测的正信号，尚非同等可行性下的稳定胜出。详见 [结果解读](结果解读.md)。

## 匹配的 2×2 对照

| 决策频率 | Progress | Feedback |
|---|---|---|
| 段间 `block` | 每个 B 开始选一次倍率，整段保持 | 相同频率，加当前 A 遗忘及近期 A loss 变化 |
| 段内 `within` | 每 5 次更新重选倍率 | 相同频率，加当前 A 遗忘及近期 A loss 变化 |

Progress 已读取新任务反馈，并非严格的开环控制。核心比较分别是同频率下 Feedback−Progress；段间与段内比较属于补充诊断，动作持续时间和相应教师标签也会变化。

原始 A 为 1–3 个输入域，随后连续学习三个新输入域。6-expert 固定几何 router、非线性专家和统一无标签冲突的教师沿用此前生成器。动作仍为 `{0,.25,.5,.75,1}`，缩放原始 A 高频专家的 **Adam 参数位移**，moment 本身不缩放；其余专家正常更新。保护组由 A 使用率 `>=1/3` 一次确定，整条序列不变，不预先查看后续 B。

每个 B 到达监测 MSE `.08` 或 100 更新步后结束，共最多 300 步，剩余额度不转移。即使某段失败也继续后续段，序列达标必须三段在各自学习结束时均达标。所有方法每 5 步监测原始 A，段间策略不能据此在段内改变动作；同一实际轨迹的观测和控制工作量代理一致。

**这里首先是连续适应原始 A 的实验，不是所有历史任务均被回放的完整持续学习协议。** A 回放、A 监测各最多 64 个样本，整条序列固定；已学 B 不加入记忆。主指标为 A 独立评估 MSE 相对 B1 前的正增量，按 A 任务平均。序列结束的每个 B 的 monitor/test MSE 及全部 B 仍达标率另行报告，防止把“曾学会”误写成“仍保留”。

## 信息隔离

共同 16 个输入：当前 B 初始路由摘要、**全局初始** A loss、当前段初始/当前 B loss、近期 B 改善、段预算与进度、上次动作、段索引、累计更新数、上一段 B 终点 loss/达标状态。Feedback 额外加入累计 A 遗忘与近期 A loss 变化，总计 18 维。Progress 在标准化后将最后两维置零。

全局初始 A loss 和 A 遗忘基准不会在换段时刷新，避免给 Progress 隐藏的段间 A 反馈。当前 B 数据只在到达该段时提供，未来 B 不作为控制器输入。最终评估数据绝不作为在线观测、停止信号或测试阶段的动作选择依据。

## 学习、选择与锁定

- 全新历史：64 train / 24 dev / 64 test；3 个匹配初始化。Pilot 使用另外的 8/4/8 历史及一个初始化。
- 每个训练历史用固定 `.5` 和带种子的随机策略各产生一条行为轨迹。段间采集活跃段起点，段内另采集局部第 10、30 步。每个状态的 5 个动作在 2 个配对未来批次流上查询（pilot 为 1 个）。
- 当前动作持续一个允许决策间隔，此后 `m=0` 到序列终点。它是固定后续策略的动作价值标签，**不是全局最优 oracle**。同频率两种信息组共用所有状态和标签。
- 两组都是 18→32→32 评分器，输出每档达标与遗忘估计；损失为 BCE + 原始遗忘 MSE + 居中 MSE，沿用 v6 的学习诊断选择。
- epoch `{0,150,450}`、slack `{0,.1,1}` 全部按 **开发集闭环** 表现选择：先达标率，再成功历史上的 A 遗忘，最后工作量。固定倍率、预定段切换/时间调度、简单反馈规则也仅由开发集选择。
- 创建任何最终测试历史前保存源码、模型哈希和所选基线。最终测试不用于修改设计。离线分支查询和开发候选搜索成本单列。
- 三个模型初始化先在每个根历史内平均，再做根历史配对 bootstrap。共同成功集合要求被比较两组的全部模型初始化均成功。另报告最大逐段终点 B loss 差 `<=.008` 的敏感性检查。区间为未校正多重比较的名义 95%。

没有同轮 K=1 对照，不能把 v6→v7 的任何变化都归因于段数。序列更长也不保证更需要旧知识反馈；只有同频率闭环对照能给出本轮的信息增益证据。

## 复现

```bash
python scripts/run_experiment.py v7 --pilot --out runs/v7-pilot
python scripts/run_experiment.py v7 --out runs/v7-reproduction
python scripts/test_all.py
```

`model_core.py` 原样复制 v6。新增连续环境在 `sequence_env.py`，监督控制在 `control.py`，实验编排在 `run_sequence.py`，配对统计在 `analyze.py`。

根目录 `scripts/analyze_sequence_diagnostics.py --run <结果目录>` 可重建事后描述性诊断与两项主要比较的多重比较敏感性检查。复现入口也会调用它；它不改变锁定的策略或原始主要分析。
