## 数据与评价

SuperNI固定revision `55a365637381ce7f3748fa2eac7aef1a113bbb82`；来源/别名及近重复组件隔离，24/8/8任务分为训练/开发/确认。本轮只执行开发前三任务 DREAM、SNLI、Financial Phrasebank。每任务保留384训练、384在线监测、128隔离评价。精确输入分组及MinHash候选后5词shingle Jaccard≥.90去重；这是近似候选检索，不能声称穷尽排除了所有近重复。元数据/来源/许可证状态见[清单](archive/data_manifest_public.json)，不提交原始样本或任务定义全文。

评价F为两个旧任务相对各自完成时固定基准的正损失增量均值；另报signed F与最终绝对答案token CE。仅保存完成时对角和最后一行，**没有完整逐段矩阵、生成任务得分或通用能力评价**。在线监测/奖励与隔离评价分开。gamma1缓存势能差分奖励最终只补一次全记忆终点项，每条轨迹验证望远镜恒等式；final eval不用于奖励。

## 结构化接口与文件

每层一个base，0/1/2个不同expert修正，倍率{0,.25,.5,.75,1}。修正值排除base；按顺序选expert、不重复，未用槽位不采样。两种expert顺序可映射同一分配，定义的是有序潜动作概率，不将其冒充合并后的分配概率。规则就在同一接口内。greedy日志中的`policy_logp`是对应平滑随机分布下的潜动作概率，不是确定性行为的实际概率。

- `provenance/pilot-executed/`：从远端取回、实际执行的精确源码；复现实测应使用这里。
- 根目录源码：最终工程代码；新增全空PPO批次跳过和阶段时限保护未在GPU pilot中触发/执行。`workflow.py`与`execution_plan.json`为**取消前的未执行草案**，不能据此填写方法结果。
- `provenance/*_v0.py`：更早未做完整历史的稠密接口工程原型；它的CPU测试不能代替稀疏接口测试。
- `archive/`：实测结果、环境版本、成本、回执、日志、公开元数据。
- `analysis/pilot/`：既有候选描述性诊断；参考`fixed1`只是均匀更新，没有完成强静态搜索。独立未来复测未知。
- `validate_archive.py`：校验真实轨迹、奖励、成本、共享前缀、潜动作概率与文件摘要。

27项CPU检查通过（11项机制/环境、16项离线诊断），包括中途保持动作的序列化恢复。真实GPU恢复检查仅覆盖短测中的可训练权重/Adam存储与冻结范围，不是一次被硬截止打断的完整历史恢复试验。
