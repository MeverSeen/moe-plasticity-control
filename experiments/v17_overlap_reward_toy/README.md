已完成，见[结果解读](结果解读.md)。新确认结果与旧测试复测分开报告；原始逐步轨迹位于`runs/v17/main/`。

对用户提出的修正做 H=1 三组对照：遗忘、全模型实际位移、重叠保护组实际位移。原 v16 代码与归档冻结；这里复制其运行器，只扩展位移记账和第三种奖励。学习器、14维输入、五档动作、PPO、训练/开发根、种子、256条轨迹与128次优化均保持一致。

保护组为旧使用率≥1/3且新使用率≥.05的expert，沿用原分组，在一条轨迹内固定。第三种奖励是 `-sum_i_in_mask ||actual_Adam_delta_i||²/s_D`，终点不达标额外罚10。全模型与保护组使用**相同**的v16训练集尺度0.6672570714168875；不按保护组大小或其代价重新归一化。这保留“只改求和范围”的对照，不能由一次结果断言其他尺度也相同。

每步分别记录各expert、保护组、非保护组和全模型的位移；相对起点的净位移另报。本轮没有改成终点净位移奖励，没有引入Fisher或新反馈特征。

五个固定倍率包括始终冻结保护组m=0。开发选模继续按达标数、旧监测遗忘、更新数；保留第0轮和最后一轮，避免把冻结初始化当作学习收益。全部模型与固定基线选定后生成新的48个确认历史1730000–1730047；旧48个v16测试历史仅作诊断复测，不称为新的独立确认。

目标仍是新任务在预算内达到MSE≤.08时的旧任务保留；惩罚10只是训练代理，并非硬约束保证。冻结保护组可能已达到零位移目标，但其余专家仍可造成遗忘，必须同时报告实际旧测试表现。若未检验混合奖励，不作混合奖励有效的结论。
