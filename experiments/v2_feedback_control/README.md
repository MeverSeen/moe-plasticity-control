# 单倍率 MoE 反馈控制实验

本轮检验：固定保护专家组之后，旧任务实时反馈能否帮助标量控制器在相同新任务目标下减少遗忘。

这是 CPU 可运行的合成机制实验，复用上一版原型的非线性专家和数据生成器。不是用户先前 4 专家线性实验的复现，也不是实际语言模型实验。

## 复现

Python 3.9+。本机已有对应依赖，不需要下载数据。

```bash
python3 -m pip install -r requirements.txt
python3 -m unittest -v test_experiment.py
python3 run_all.py --out results/reproduction
```

输出目录必须为空。测试前写入配置和权重哈希；脚本拒绝覆盖已有结果。

## 对照和控制变量

- 6 个 10→12→1 tanh experts，固定 top-2 router，固定 870 个学生参数。
- A 表示 1–3 个旧任务的历史；每次 B 开始时所有策略共享同一个历史模型、数据、优化器初始状态和批次随机序列。
- 旧样本预算为 64 个回放样本＋64 个监测样本；随旧任务数平均分配。测试样本独立，策略无法访问。
- 保护组在 B 开始时确定并冻结：旧 top-2 usage ≥ 1/3 且当前 B usage ≥ 0.05。其余专家倍率固定为 1。
- 每 5 个更新步骤决策一次，保护组倍率从 `{0, 0.25, 0.5, 0.75, 1}` 选择。
- 倍率作用于 Adam 最终参数位移，基础梯度为新任务梯度＋0.1×固定旧数据回放梯度。无 Fisher、无额外保护正则项。
- 路由和分组不随动作改变。本轮隔离的是倍率控制收益。

比较全更新、开发集选定的最佳常数、两阶段进度调度、旧损失阈值反馈规则，以及同结构的 progress PPO 和 feedback PPO。两种 PPO 唯一输入差异是当前旧知识退化与近期旧损失变化；共有相同初始信息、新任务进度、剩余预算及上次动作。各训练 3 个匹配随机初始化。

固定倍率搜索 5 个候选；进度调度搜索 75 个候选；简单反馈规则搜索 48 个候选。两种 PPO 各使用 64 个训练历史、60 轮×12 个 episode，并在同一 24 个开发历史上选择检查点。训练候选数量和实际计算开销均保留，不宣称各类方法的离线调参成本相同。

## 目标、预算和数据隔离

主要终点为新任务监测 MSE ≤ 0.08 的首次穿越。这个目标只用 12 个预跑历史校准：0.06 时全更新达标 9/12；0.08 和 0.10 均达标 12/12，选择较严格的 0.08。

所有方法在线使用同一工作量上限：前向一个样本记 1 单位，前向＋反向记 3 单位，控制网络线性层 MAC 折算为学生前向单位。初始观测、路由统计、每步新任务监测和每个控制窗口的旧任务监测均计费，同时上限为 300 次更新。这是**明确规定的工作量代理，不是精确硬件 FLOPs 或相同运行时间**。所有方法执行相同监测流程，进度控制器仅隐藏旧任务反馈，属于信息消融实验；真实部署中不读取旧反馈的方法可能省去部分监测成本。

策略训练用失败惩罚加成功终点遗忘代价，并加入折扣为 1、终止势函数为 0 的势函数塑形。成功代价为 `-min(F_monitor/0.01, 5)`；失败代价为 `-10-min(log(L_B/target),5)`。这是约束目标的训练代理，不保证达标。验证选择先比较达标数量，再比较达标时旧监测遗忘，最后比较工作量。报告同时包含失败，禁止只凭成功子集宣称胜出。

训练种子 230000–230063；开发 240000–240023；最终测试 250000–250079；均与上一版已查看的测试种子不同。最终测试包括 80 个独立历史。每个历史中持续控制一次 B 学习，不是控制器从第一任务起接管完整长序列。测试数据只在锁定全部配置与模型后生成。

遗忘 = 每个旧任务的测试 MSE 相对 B 开始时的增加量取正部，再平均；单位为 MSE。它衡量本次 B 引入的退化，不是相对历史最好表现的累计遗忘率。

## 分析

主要比较为匹配训练随机种子的 feedback PPO vs progress PPO。按完整测试历史配对 bootstrap；同时报告每个策略训练种子的结果。将三次训练先在每个历史内平均，避免把 240 个结果当成 240 个独立历史。另提供仅作敏感性参考的双向 bootstrap，三次训练不足以精确刻画训练随机性。

遗忘配对区间只在共同达标集合上计算，必须结合全体达标率解读。另提供更紧的新 loss 匹配、排除零更新达标的敏感性分析，以及包含失败的全部终点指标。

## 文件

- `experiment.py`：环境、分组、控制器、PPO、调参和锁定测试。
- `model_core.py`：从 v1 保留的数据和学生模型实现；本轮不使用其中的旧控制器。
- `test_experiment.py`：8 项有效性检查。
- `analyze.py`：配对统计、端点 CSV 与独立 PNG/PDF 图。
- `results/pilot/`：预跑和门槛校准记录。
- `results/main/data/`：正式配置、调参、训练、权重、锁定协议和原始测试轨迹。
- `results/main/analysis/`：正式统计和图表。
- `实验报告.md`：本轮结果及其可支持的结论。
