# v12：持续动作与联合模块控制（GRPO）

2026-09-20。v10、v11及更早版本冻结；当前分支codex/v10-visual-control上的独立新版本。本轮只训练GRPO，不运行PPO。不是GRPO最优、算法无关或动态控制有效的预设证明。

## 单因素对照

| 组 | 动作范围 | 保持长度 |
|---|---|---:|
| A | 固定expert基础，每层至多改1个expert，另控trunk | 10更新 |
| B | 与A完全相同 | 50更新 |
| C | trunk＋全部8个expert，无修正数量限制 | 50更新 |

倍率沿用v11：expert为0/.25/.5/.75/1/1.5，trunk为.25/.5/1；头保持1、router权重冻结，不增回放/容量控制。对实际AdamW候选完整位移含decay进行缩放；零倍率推进有梯度参数的一阶/二阶矩，grad=None跳过。首任务统一expert1/trunk1，控制器从第二任务介入。

每10步环境检测同一monitor目标loss1.25，预算200/任务；50步持有也会在中间检测达标时立即结束。为保证观测字段的含义和成本可比，所有组每10步刷新相同环境摘要；持有期间策略不能读取这些中间观测或重选。每次实际采样只保存1条GRPO transition，并记录其实际持续更新数；任务末尾可短于保持长度。中途恢复保留持有动作、剩余区间、模型、Adam、记忆、数据位置和观测状态。

## 初始化与协同探索

复用v11的8校准根，并在真实数据上验证固定策略路径逐数一致后复用64条固定结果；新运行80条补齐6×3静态网格。所有候选、旧结果来源和新增成本单独记录。选择成功率、累计F、最终绝对loss的字典序最优可行策略；不足90%须明确标不可行。选中expert=.25/trunk=.5（8/8达标，F=.038345）。新选择根1240000–1240007、复测根1250000–1250011不会用于重新选择初始化。

三组共用局部、层级、全局共享编码器和同一探索层级。每次先抽保留基准/探索（初始化各.5）；保留分支直接执行整份固定基准。探索分支抽trunk（基准概率.5），共享expert锚点（基准概率.5）、两个层级模式（各以.8概率跟随共享锚点），再抽expert倍率（.8概率跟随层级模式）。A/B只在每层抽1个修正对象；C为全部8个expert抽倍率。共享离散变量使层内、层间探索相关，不是9个独立近固定开关。贪心初始化取保留基准；随机执行保留整份基准概率至少.5，仍有充分协同探索。增加可变expert数量自然改变实际动作扰动幅度；B→C同时体现联合动作支持与该探索分布的效果，不能声称纯动作维数因果效应。

保存完整潜变量及其链式联合log概率；训练按相同条件概率重算。相同实际动作可能由多个潜路径产生，优化对象是合法潜变量策略，不误当唯一动作概率。熵项沿采样条件路径计算，三组一致。

## 计算预算与评价

训练起点由12个新训练根1230000–1230011各自完成首任务得到。4个策略种子1201–1204；每GRPO组从同一完整起点克隆4条真实闭环轨迹，根循环使用。每策略训练以20,000个**分支learner更新**为目标，完成跨越预算的最后一整组后停止；最多多4×3×200=2400更新，最多64组仅作故障保护。前缀、观察、评估和克隆另记。按实际更新预算比较，不称分支条数、优化次数完全相同。

检查点为初始化、首次跨10,000更新、首次跨20,000更新。GRPO学习率.001、两次联合ratio clip(.8,1.2)更新、梯度范数1、熵系数.002、组优势标准差下限.1；三组一致。终局reward沿用原有限monitor累计正增量/0.1及每失败任务−3，不在本轮同时更换reward。记忆保持200（回放100/monitor100）。策略优化次数、控制决策数、观察样本数、分支复制和全部learner更新另报。

8选择根分别按greedy/随机执行选择检查点；12复测根运行初始化、末轮、两种选中检查点的并集。每根一条固定配对动作RNG流，接口潜变量数量不同，不保证每个潜动作逐一耦合。报告A→B、B→C、各组学习后−初始化、各组−最佳固定基准，失败、终点loss和成本一并保留。强静态基准、接口合法的进度/反馈规则在相同选择与复测根上运行，规则阈值预先固定，不按复测调参。

开发类别池60–79已多轮使用，新增根仅是顺序/初始化开发复测，不是新类别最终确认。训练仍限0–59；不查询80–99任务或官方test成员。完整研究eval矩阵不进入策略观测或GRPO reward。

轻量核验：实际位移、Adam矩、10/50步相同停止、每保持区间只采样一次、持有中途完整恢复、联合动作支持及联合log概率逐数一致。另做真实数据1000次采样覆盖及各组4分支GRPO短测，完成后才冻结完整运行预算和源码hash。
