# 轨迹数据复用说明

本轮的独立训练来源是4条任务历史根；同根不同行为共享相同的 A 后初始状态。expert 条目、控制窗口和同根分支不是独立任务样本。开发与确认根不进入拟合。

## 保存内容

| 文件 | 内容和用途 |
|---|---|
| `code/`、两份 `source_lock.json` | 实际执行源码及哈希；旧版本依赖一并冻结 |
| `protocol.json` | 模型修订、数据划分、目标规则、预算、奖励和学习超参数 |
| `data/references/`、`targets/` | 每根重新校准的参考轨迹和由其生成的目标 |
| `data/prefixes/*.pt` | A 完成后的 LoRA、完整 Adam、随机状态、记忆和趋势摘要，可真实恢复后继续学习 |
| `data/results/train/*.json` | 完整 B/C 轨迹、动作、概率、观测、原始监测 CE、终点和成本 |
| `data/adapters/*.pt` | 每条训练分支的终点 LoRA；配套 JSON 保存内容哈希 |
| `data/offline/` | 固定数据清单、三种奖励重标数据、BC/IQL 控制器及训练记录 |
| `data/results/development/`、`confirmation/` | 冻结控制器的真实闭环执行；不能回流训练 |
| `data/selection_lock.json` | 用完整开发根选中的单一 IQL 候选及控制器哈希 |

每个控制决策保存10维 expert 特征、10维全局特征、结构化有序潜动作、实际16×64倍率、联合行为 log 概率和实际持续步数。确定性行为的概率为1，因此实际 log 概率为0；不能用带平滑策略的概率替代。

每步保存已有的新任务训练 CE、停止监测 CE、实际 LoRA 因子位移平方和及逐 expert 分量、计算成本；控制边界另存监测样本 ID、原始旧 CE、固定基准。完整终点保留全部监测旧任务 CE，以及相对同根 A 后前缀的有效 LoRA 权重 `BA` 距离。

不保存每步完整梯度或全模型权重。可恢复状态保存在根前缀，而非每个控制窗口；从任意中间位置追加分支需要从前缀重放已记录动作，并核验复现。基础模型按固定修订重新加载，训练数据、tokenizer、软件版本和数值设置必须匹配。r2 的确定性验证属于当前硬件和软件组合，不承诺跨版本逐位复现。

## 可离线重算的内容

原正部遗忘、旧任务绝对 CE、有效 `BA` 距离及不同固定权重组合，均可由原始终点重新标注。任意新增奖励若依赖没有记录的量，必须补做真实测量。最终任务评价和通用能力评价用于独立诊断，不用来设计训练样本的奖励或拟合控制器。

第一版导入器只接收完整历史。A→B→C 的任务切换不终止 episode，只有整条历史结束才设置终止并加入终点奖励；时间预算截断单独保存，不伪装成任务失败。全零原奖励仍然保留，不能筛掉以制造可学习性。

IQL 用真实执行动作的价值学习和优势加权联合潜动作似然；BC 使用同一轨迹、相同策略结构与相同 actor 更新次数。各 expert 不能拆作拥有同一个总回报的独立样本。离线分数、动作命中率和训练损失都不是闭环改善的替代指标。

## 结论限制

距离奖励保持更新小，不能自动保证旧功能不变。三种奖励的尺度与失败惩罚已锁定，但没有被证明精确表达“先保证全部达标”的词典序目标，最终仍单列失败数和共同达标历史。

本轮固定最终训练检查点，不做超参数或训练种子搜索。小数据下价值拟合和行为覆盖可能限制学习效果。确认任务池之前已曝光，只能报告重复留出池复测。完整原始记录应保留，让后续方法在相同数据和相同评价接口上比较。
