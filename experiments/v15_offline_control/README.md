# 固定 MoE 控制接口上的离线数据与奖励比较

2026-09-20 用户授权连接现有 A800，集中采集可复用轨迹，再离线训练控制器；另明确允许从确认时起最多新增8小时。本轮保守硬截止为21:15 UTC，不购买或扩容。

沿用 OLMoE 全16层、64 experts/层、rank4 LoRA、H=5，以及 v14 的10维局部/10维全局观测和分层稀疏动作。主要变量是终点奖励：原正部遗忘、旧任务绝对CE、有效LoRA权重变化。后两者是不同的代理目标，不宣称与遗忘等价。

锁定协议见 [protocol.json](protocol.json)。最多采集4根×8种行为的32条完整历史，先验证相同检查点/动作复现。完整历史按根隔离；复用A前缀但B/C由真实模型重新执行，不能把重复观察、expert数量、共享前缀或梯度步当独立历史。

日志保存完整观测、结构化latent、实际倍率、行为概率、持续步数、每步已有loss/成本、原始监测样本ID/CE/固定基准、完整终点和有效BA距离。每根保存完整可恢复前缀，每条完整训练历史保留终点适配器。Adam/RNG/记忆/趋势状态与因子一起恢复，不修改v14档案。不同动作的后果必须真实执行，不能从同一原梯度伪造。

离线方法仅BC与IQL。IQL使用双Q、expectile V和优势加权联合latent似然；不把每个expert当成独立监督样本。不重复用历史数据冒充标准on-policy PPO。第一版仅导入完整历史，任务边界不终止；预算截断另存且不伪造失败或零价值。

三种奖励用同一批轨迹，gamma=1。IQL训练1200步、单种子；控制器结构不变，固定末轮模型。有效权重距离的尺度仅由训练固定.5轨迹按预定公式产生并锁定。两开发根选一个IQL候选，再与固定1/固定.5/规则/BC在两隔离根闭环复测。确认任务池此前已在报告中曝光，新种子不等于新任务，不能称全新最终确认。

控制器输入和奖励都不读取隔离eval或通用评价。原始这些指标只进入开发选模与最终报告；采集训练历史中的eval保留为诊断，成本计入，不用于拟合。

## 复用旧数据

旧v14训练轨迹可用 `dataset.py` 导入原终点目标，作为流程检查。缺少原始绝对CE或有效距离时明确拒绝相应重标，不能从截断后的遗忘反推。确认记录禁止进入导入器。旧轨迹8条/83决策、零终点奖励只支持通路验证。

## 参考

- [IQL](https://arxiv.org/abs/2110.06169)：固定离线转移上的价值学习与优势加权策略提取，不能消除覆盖不足。
- [PPO](https://arxiv.org/abs/1707.06347)：交替采样与有限轮更新，不作为本次固定日志训练器。
- [EWC](https://arxiv.org/abs/1612.00796)：参数变化代理需要考虑旧功能的重要性；裸距离不是遗忘的等价量。

所有实际数量、时长、未完成情况和恢复诊断最终写入结果记录；计划数不冒充已完成数。

## 确定性修订 r2

首轮在第二个训练根的同动作 5 步复现检查失败，已停止，未产出正式训练历史。完整恢复的权重、Adam、随机状态与保存值一致；使用固定 CUDA 工作区及确定性算法后，原失败检查点的两次 5 步重放 loss、权重和 Adam 完全一致。这定位到了数值执行设置相关问题，尚未定位到具体算子。

r2 启用 `CUBLAS_WORKSPACE_CONFIG=:4096:8` 和 `torch.use_deterministic_algorithms(True)`，所有目标重新参考校准，通用能力起点也重新测量。每根仍执行成对恢复检查，首条完整历史仍重复验证。r2 数据目录独立，不能混用首轮或旧版本数值轨迹。授权截止仍为 21:15 UTC，未重置预算。
