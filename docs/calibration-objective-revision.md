# 校准目标修正：冲突形态不是必要条件

2026-09-16，根据用户对 v4 后续建议的修正。

“低倍率学不够、高倍率遗忘大”是一个可检验的机制，不是动态更新控制产生价值的必要条件。此前将优先寻找这一形态作为下一步，范围过窄。

即使所有固定动作均能达标，仍可能存在：不同历史偏好不同可行动作；不同学习阶段安排更新可减少累计损伤；按实际状态响应可优于仅按进度安排的策略。这三层主张必须分别检验。

## 本轮校准要检验什么

在同一新任务目标和在线预算内，状态条件化或时序安排能否产生独立未来样本上可复测的决策收益。结果同时报告达标率与相同阈值终点遗忘，不以动作 argmin 分布不恒定代替收益。

1. 最佳全程固定倍率：确定静态对照。
2. 校准集选定的单次切换时间/进度策略：检验有限时序安排相对固定倍率的收益。
3. 每历史从有限计划中用未来流 0 选择、在独立流 1 评价的特权参考：检验历史相关的计划选择潜力；不是可部署控制器，也不证明需要实时反馈。
4. 在选择流中所有固定动作可行的子集中重复诊断，并报告评价流的失败，避免只检查“低倍率失败”的情形。

校准扫描同时包含原 v4 的 0.08/300 设置。候选选择不要求低倍率失败，不要求遗忘随倍率单调增加；不强行筛出正结果。配置和基线只在新校准历史上选择，再对新确认历史评价。所有扫描结果都保留，若确认不支持就明确报告。

有限候选的特权参考不是理论最优，也不是严格的策略性能上界。它的分支成本另计，正结果还必须经过可用特征预测、强进度基线和闭环验证才能支持反馈控制；长时收益不自动证明 RL 必要。

当前阶段不修改 router，不引入新的状态表示、RL 或更大模型；真实 MoE 路由改进见 [后续待办](future-real-moe-routing.md)。
