更新于 2026-09-17。本页是当前研究主线与实施规划入口；算法细节见 [控制器设计](controller-design.md)，已经取得的证据见 [研究记录](research.md)。

**实施更新（2026-09-20）：v12持续动作与联合控制已完成。** [四种子结果](../experiments/v12_persistent_control/结果解读.md)显示，保持50步减少约75%的策略决策，但未产生稳定遗忘改善；放开8个expert联合控制的随机复测结果比稀疏接口更差。11/12个greedy模型选择初始化，唯一改变是另一种静态trunk倍率。全部主要策略10/12根达标，受首任务失败限制；强静态参考仍须保留。结果不支持将参数更新、探索变化等同于状态反馈价值，也不证明联合控制或GRPO在其他预算下无效。

**主平台决策（2026-09-20）：下一阶段固定为原生 OLMoE 全16层、64 experts/层的低秩适配控制。** 每个expert三个投影加rank4 LoRA，共37,748,736可训练参数；冻结基座与router，保持原生路由。整条历史共用一套持续更新的适配器，跨独立历史恢复同一初始化。控制LoRA因子的实际AdamW位移；零倍率保留已学适配器的前向作用，同时缩放A/B位移不等于严格线性缩放有效BA变化。

v13仅完成两层原生权重工程短测和单根三候选比较，因平台调整提前结束；[结果](../experiments/v13_native_ppo/结果解读.md)保留有限范围证据，正式PPO收益未检验。v14先验证接口和实测成本，不作全层优于两层的因果比较。主表固定为固定分配（均匀更新与开发期强静态参考）、同信息同接口规则、学习控制器（PPO候选），克隆放诊断表。之后围绕同一平台积累证据。下文旧视觉、独立LoRA experts及GRPO规模保留为历史候选，不能覆盖本次平台决策。

新评价分列新任务达标/答案loss/任务得分、相对各任务完成时的累计遗忘、相对整条历史开始前的通用能力变化，以及内层/外层/监测/在线控制/墙钟成本。通用评价始终开启同一部署适配器，逐能力保存初始与终点绝对值；首版只作隔离评价，不加入PPO奖励。未来若主动优化保护，必须另立隔离在线代理并计入记忆预算。

## 1. 研究主题

在固定模型容量、有限旧记忆和可核算的计算成本下，用共享控制器协调各 expert 的实际参数更新，使模型达到指定新任务验证 loss 时，累计旧知识退化更小。

重点研究状态依赖的联合分配：某个 expert 应更新多少，可能取决于其他 expert、层间表示、当前材料、过去更新及剩余预算。学习还可能把昂贵的在线搜索摊销为快速决策。规模大本身不证明规则失效；同信息、同动作、同预算下真正最优的规则无法被学习方法超越。

三个问题分别检验：

| 问题 | 主要比较 | 能支持的结论 |
|---|---|---|
| Q1：控制接口有无价值 | 全局/固定分配、两组、逐 expert，匹配倍率范围 | 更细的更新分配是否改善可达到的结果 |
| Q2：观测有无增益 | 充分的 Progress，再加旧知识反馈/历史/当前路由 | 额外信息是否改善实际闭环决策 |
| Q3：怎样学好控制器 | 同接口强规则、监督控制、PPO、GRPO | 学习方法的效果、成本与泛化 |

不要求四 expert、单标量环境先稳定击败规则，才允许进入多层逐 expert 方法。也不把“长期规划有用”写成“RL 必不可少”。既有正负结果保留，不用新的研究定位改写其结论。

## 2. 方法主线

内层仍由 Adam/AdamW 产生候选更新，控制器每个窗口输出逐 expert 倍率：

$$
\theta_{\ell,i,t+1}
=\theta_{\ell,i,t}+m_{\ell,i,t}d_{\ell,i,t}^{\rm optimizer}.
$$

倍率作用于实际参数位移；动量、权重衰减、未激活专家和零倍率时的状态更新须在实现中明确。零倍率不自动节省前后向计算。

共享编码器读取局部摘要，再经层内汇总和全局协调，输出各 expert 动作。输入包括历史/当前路由、学习进度、旧知识反馈、候选位移、上一动作以及观测的覆盖量和可靠性。冻结 router 权重不等于固定路由；多层模型必须记录上游表示引起的变化。

最终动作可以是高维的，探索采用结构化变化：可行基础分配、层/组模式和稀疏局部修正。小规模的因子化逐 expert 策略保留为参照；不用为每个 expert 训练独立 agent，也不必对全部专家做两两注意力。

GRPO 从同一完整 learner checkpoint 克隆若干闭环轨迹，用组内实际学习结果训练控制器；PPO 保留为匹配交互预算的算法对照。部署控制器冻结，单轨迹执行。概率、奖励、数据权限与计算记账细节见 [算法方案](controller-design.md)。

## 3. 三层证据路线

三层是不同的证据范围，按成本逐步实施；不是同时启动三个项目。

| 层次 | 候选平台 | 主要用途与结论范围 |
|---|---|---|
| 第一层：标准视觉任务 | La-MAML 式任务划分＋小型多层 MoE | 完整方法训练、动作/反馈/协调消融及未见历史测试 |
| 第二层：语言适配专家 | CP-MoE 式冻结 Llama-2-7B＋LoRA experts、SuperNI | 验证语言持续学习中的适配专家控制 |
| 第三层：原生 MoE | OLMoE-1B-7B-0924 等可运行公开模型 | 验证原生专家结构及更大规模上的方法边界 |

第二层成功不能单独支持原生预训练 expert 权重的可塑性结论。如果论文的主张覆盖原生 MoE，应提供第三层相应证据；只控制原生 expert 内新加 adapter，也应明确这个范围。

### 3.1 历史视觉入口：小型多层 MoE

拟采用小型 CNN 前端、两个残差 MoE 块，每块 8 experts、top-2；expert 可从 128→256→128 的 MLP 起步，每 5 次更新控制一次。这些是工程候选，不是文献标准配置。先跑短序列检查训练，再研究更长历史和更多专家；是否使用 5/10/20 任务须与类别隔离方案共同决定。

任务协议借鉴 [La-MAML §5.2/附录 G](https://arxiv.org/pdf/2007.13904)：CIFAR-100 为 20×5 类任务，TinyImageNet 为 40×5 类；多遍训练最多 10 epochs/任务，回放样本上限分别为 200/400，采用任务增量多头分类。我们更换模型、加入监测记忆并采用目标 loss 停止后，应称为协议适配，不能当作原论文复现或直接比较其表格数字。

在正式运行前锁定：前端/分类头/共享 expert 的训练范围，任务 ID 是否可见，router 参数是否训练，真实样本分配是否固定，总旧样本预算及回放/监测分配。若前端有预训练，说明使用哪些类/数据，避免预先接触声称未见的测试任务。

为拆开专家协调和路由迁移，可先设固定样本路由的机制变体，再单独引入隐藏表示驱动的动态路由。增加专家数时同步记录容量余量、每 token 激活计算、任务难度和训练成本；更多闲置容量可能让冻结规则更强，不能预设优势随 expert 数单调增长。

### 3.2 历史语言候选：独立 LoRA expert 控制

[CP-MoE §4/附录 B](https://arxiv.org/html/2605.20247v2) 提供起步依据：冻结 Llama-2-7B，在 q/k/v/o 与 gate/up/down 投影使用 8 个 rank-4 LoRA experts，dropout 0.1；AdamW 学习率 2e-4、cosine decay、每任务 5 epochs、每设备 batch 16。其 SuperNI 设置包含 8 个连续学习任务和 7 个零样本任务，两类评价分开。

正式实验应从原文及官方配置锁定任务 ID 和数据版本，再统一目标 loss、总记忆和预算重跑基线。原方法的临时专家、10,000 tokens 预热及整合机制计入完整复现成本；只借保护机制时标为适配基线。

“每模块 8 experts”不等于全模型只有 8 个动作。控制单元必须在每投影分支、层内同编号分组或跨投影绑定之间明确选择；先声明绑定，再计算动作数。

外层训练使用隔离的 SuperNI 任务/来源。[数据集原文](https://arxiv.org/abs/2204.07705) 报告 1,616 个任务、76 种类型；相关来源和近重复任务放在同一划分。TRACE/SETA 可作为第二任务分布候选，完整训练配方核对后另立协议。

### 3.3 原生 MoE 阶段

[OLMoE 官方配置](https://huggingface.co/allenai/OLMoE-1B-7B-0924/blob/main/config.json) 为 16 层、每层 64 experts、每 token 选 8 个，共 1,024 个 expert 位置。先对选定层做显存、吞吐、监测与 checkpoint 复制测算，再决定可训练范围、学习率和 rollout 长度。不能直接沿用 LoRA 的更新尺度。

DeepSeek-V4.1-Flash 的 40×384 路由 experts 仅用于说明规模动机，非当前实施平台；主干计 15,360 个路由专家，另有 40 个共享专家，不含附加模块。事实依据及范围见 [官方配置与实现记录](references.md#deepseek-v41)。

## 4. 评价协议：等新任务表现与累计旧知识

### 4.1 先锁定“学到同样程度”

在训练/开发环境确定每任务目标 loss 或其生成规则；正式测试开始后不能根据各方法结果挑阈值。不同任务不必共用一个 loss 数字。所有方法使用相同监测集、检查频率、停止规则和最大预算。

报告初始即达标任务、全部失败、实际终点 loss、达标步数及最终保留。先检验预定达标率要求，再比较共同达标历史的配对遗忘，并做 loss 匹配敏感性分析；成功子集不是全分布优越性证明。语言交叉熵达标之外，另报相应准确率/生成质量。

主图呈现遗忘—新任务 loss—成本的关系。若控制器读取目标 loss，不同目标会改变其行为，不能把一个目标产生的轨迹重新截断，冒充全部其他目标下的策略运行。

### 4.2 单段损伤与累计遗忘分开

设 theta_k 为学完第 k 个任务后的模型，M_{k,j}=L_j^{eval}(theta_k) 为不重新适应时的任务 j 测试损失。完整保存任务表现矩阵 M。主要累计损失型遗忘候选为：

$$
F_k^{\rm cum}
=\frac{1}{k-1}\sum_{j<k}
\left[M_{k,j}-M_{j,j}\right]_+,\qquad k>1.
$$

M_{j,j} 是该策略学完任务 j 后的固定基准，不能每次进入新任务就重置。另报带符号变化、旧任务改善（positive backward transfer）及最终绝对表现，防止通过较差的初始任务学习换取较低“遗忘”。若用各任务固定尺度归一化，尺度也只能在开发阶段确定。

M_{k,j}−M_{k-1,j} 描述本段造成的损伤，不能替代上述累计量。不同任务完成时先前知识可能已被损伤，因此只最小化最后一段的增量会漏掉早期遗忘。k=1 无旧任务时单列，不伪造可比较的旧任务平均。

在线输入/奖励使用有限旧记忆的代理；最终矩阵使用隔离测试集，两者不能混用。每学完一个新任务，按锁定规则更新有限记忆，并保存各任务基准和覆盖信息。总样本预算不随任务数隐式增加，少数或未覆盖任务的代理不等于全部旧能力。

v7 仍是固定原始 A 记忆的结果；上述全部历史协议用于新版本，不追溯改写 v7。

## 5. 元训练数据与泛化主张

借鉴 [RMM](references.md#rmm) 构造合法伪持续学习历史，借鉴 [Replay Scheduling](references.md#replay-scheduling) 测试冻结控制器在新顺序、初始化和任务条件下的表现。内层材料与外层“历史—动作—真实结果”分别统计。

根历史先划分，再生成 checkpoint、分支和增强。learner 训练/回放、在线监测、外层回报和最终测试各有用途边界；前三级保留的旧数据按协议计费，最终测试不得用于动作或选择模型。

| 泛化主张 | 所需划分 |
|---|---|
| 未见历史/顺序 | 原始任务可相同，但顺序、初始化、根历史隔离 |
| 未见类别/任务 | 类别、任务身份及相关来源隔离 |
| 跨平台冻结迁移 | 不重新训练控制器，直接在新架构/数据平台部署 |
| 方法跨平台有效 | 每个平台分别元训练；不能称同一控制器跨平台迁移 |

近期优先检验平台内的未见历史与未见任务。CIFAR-100 全部 100 类用于元训练后只换顺序，只能支持历史泛化；若做类不相交划分，可用的最终测试类别就不足完整 20×5，除非另有元训练数据。两种协议分开命名，不在同一结果中兼称。

元训练覆盖简单规则足够和联合分配有机会的情形，不筛选有利结果。分别画“固定历史池、增加训练轮数”和“固定交互量、增加独立历史覆盖”学习曲线。

## 6. 对照与归因

优先固定一个完整候选，再逐项替换，不做昂贵的全因子穷举。保留以下四类，以区分“能协调”和“通过学习获得协调”：

| 方法 | 允许的信息与机制 |
|---|---|
| 局部规则 | 根据每个 expert 的局部摘要决定倍率 |
| 共享局部学习器 | 学习局部非线性映射，不读取其他 expert 的动态摘要 |
| 协调规则 | 同信息风险排序、层内配额、有限更新预算等联合分配 |
| 共享协调学习器 | 局部编码＋层/全局上下文，学习联合分配 |

四类的局部/联合信息差异是明确的消融；协调规则与协调学习器必须拿到相同观测。配额不限制候选模型容量，作为决策策略本身描述。另有最佳固定分配、进度/时间调度、全局倍率及合理范围的非 RL 更新学习参照。

动作粒度比较匹配倍率字母表，算法比较匹配 learner 交互量及开发搜索预算。PPO 与 GRPO 都记入失败、分支、观测、复制、通信及外层训练成本。全方法复现与机制适配分别命名，不以已发表分数替代统一协议重跑。

## 7. 小模型 GRPO pilot 候选

以下用于测算和开发，不是已批准的正式配置，也不是直接照搬文献超参数。

| 项目 | 候选 |
|---|---|
| 共享局部编码 | 两层 MLP、隐藏维 64；层内/全局池化＋小 MLP |
| 历史模块 | 首版使用摘要，窗口/GRU 单独消融 |
| 每轮起点抽取数 B | 4 |
| 每起点轨迹数 G | 4；8 作为后续单项对照 |
| 决策间隔 H | 5 次内层更新 |
| 每轨迹训练预算 T | 单段最多 200 次内层更新 |
| 外层轮数 U | 先考察 200，确认训练行为后再考虑 1,000 |
| 控制器学习率候选 | 1e-4、3e-4 |
| 策略更新 | 每批新轨迹先做一次更新 |
| 随机性 | 调试可用 3 seeds；正式目标为至少 5 个独立控制器种子，最终预算另锁定 |

单配置、单 seed 上限 U×B×G×T=640,000 次 learner 更新；U=1,000 时为 3,200,000 次。前者两种学习率、五个 seeds 就是 6,400,000 次，尚未计入初始历史训练、基线、观察和评价。200 轮×4 起点只是 800 次起点抽取，不能声称 800 条独立历史。

先做短运行测量吞吐、峰值显存、复制成本、组内有效优势、失败比例及策略是否真的改变，再锁定预算。单段 pilot 只检查学习与接口，不能替代多任务累计遗忘实验。7B 阶段重新测算 B/G/T，不照搬小模型数量；只复用相同合法前缀，动作分歧后的真实结果不能用旧缓存替代。
