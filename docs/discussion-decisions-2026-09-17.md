# 2026-09-17 讨论决策与证据边界

本记录整合工程创建以来的研究讨论，重点保存两组动作、逐 expert 控制、GRPO 及最新外部意见。已运行结果以冻结报告为准；设计不自动成为实现，外部意见不自动成为项目决策。

## 1. 当前已确定的研究原则

| 编号 | 决策 | 理由/边界 |
|---|---|---|
| D01 | 项目围绕结构化更新接口组织，标量倍率只是特例 | 不把全部研究价值押在一次 Feedback−Progress 比较上 |
| D02 | 允许少量旧数据，容量、记忆、计算必须明确 | 监测/奖励数据与最终测试隔离，额外旧数据不免费 |
| D03 | 当前动作缩放实际 Adam 参数位移 | 不能把原始梯度缩放默认为相同操作；冻结参数与冻结矩不同 |
| D04 | 研究学习与规则的公平比较 | 同条件下真实最优规则不可被超越；规则可非线性，学习可发现简单规律 |
| D05 | 不要求特定“低倍率失败、高倍率遗忘大”冲突 | 跨历史选择、时序安排、专家配合也可能有价值；不筛选正结果 |
| D06 | 区分动作能力、观测信息、学习算法 | 扩动作空间的理想收益不保证有限训练结果；长期收益不等于 RL 必需 |
| D07 | 模型筛选依赖开发集实际闭环结果 | v6 表明离线拟合或分支评分不足以筛选部署行为 |
| D08 | Progress 也是使用 B 反馈的控制器 | Feedback 对照通常检验额外旧知识反馈，而非“有反馈 vs 完全无反馈” |
| D09 | 新版本、独立最终测试、冻结旧结果 | 不覆盖 v1–v7；查看过的测试不用于新方案首次确认 |
| D10 | 真实 MoE 动态路由后续处理 | 已记录历史/当前路由、上游变化及保护对象迁移问题 |
| D11 | 主线推进共享、分层的逐 expert 控制 | 局部摘要经层/全局协调；不要求标量反馈先胜出 |
| D12 | 高维输出使用结构化探索，并记录观测可靠性 | 输出维度不等于独立探索维度；未覆盖不等于安全 |
| D13 | 新版本分别评估单段损伤与全部历史累计遗忘 | 保留各任务学完时基准及完整表现矩阵，v7 不追溯改定义 |
| D14 | 目标 loss 和泛化协议在开发阶段锁定 | 换顺序、未见任务、跨平台冻结迁移分别表述 |
| D15 | 视觉、语言适配、原生 MoE 是三层证据路线 | 先测成本逐步实施，数值候选不视为已锁定排期 |

## 3. 最新外部意见：吸收、修正与保留

来源是用户提供的“可以扩展到逐个 expert 控制，也可以直接尝试 GRPO”分析。本记录保存项目判断，不把第三方文本的所有建议视为用户确认。

**吸收：**

- 局部二阶交互为专家联合更新提供具体动机，但不是实验事实。
- 共享局部编码与全局上下文优于为每个 expert 单独训练 agent。
- RMM 伪任务、VeLO 分层结构、Celo 动力学增强/分阶段训练可直接启发方法设计。
- 内层材料与外层学习情境分开；通过根历史隔离及当前策略采样改善训练数据。
- GRPO 控制小型策略网络，内层继续 Adam；同起点比较完整闭环轨迹。
- 允许直接开展方法训练，并保留成本匹配的 PPO 与规则对照。

**修正：**

1. v7 保护组是 A 使用率不低于 1/3 的固定集合，不是动态 A/B overlap。新的路由分组需命名为新变体。
2. 五档逐 expert 倍率上限为 1，不包含已安排 15 动作中的 m_U=1.5；比较粒度须匹配动作范围。
3. 交互项可能为零；发现非加性仍不意味着神经网络或 RL 必不可少。
4. 带符号遗忘差分在 gamma=1 时可与终局目标等价，不能把它与“每步只惩罚损伤”混为一谈。
5. GRPO 分母下限缓解极小差异放大，但不保证绝对可行性，也不消除跨起点权重变化。
6. functional burden、Fisher、注意力、循环状态是候选，不能同时加入后把收益全归因于动作或算法。
7. CP-MoE/SETA 的结构和 router 条件与本项目不同；直接复现与借用其保护机制的同预算适配基线应分开标注。

## 4. 用户报告的早期正结果：保留来源等级

以下来自对话中的用户报告，未在本工程找到相应原始代码/数据，不属于 v1–v7 的已归档复现。数字用于保存研究动机，不并入工程主结果。

### 4.1 专家身份/路由共享的受控实验

4 experts；旧 A 使用 E0；B_low 使用 {E2,E3}，B_high 使用 {E0,E2}；gate 为 0.8/0.2，起始相关专家函数相同。50 seeds，新 B 目标验证 loss 小于 0.005。

报告的部分结果：

| 主专家倍率 | 平均达标步数 | 低 overlap 遗忘 | 高 overlap 遗忘 |
|---|---:|---:|---:|
| 0 | 635.5 | 0 | 0 |
| 0.4 | 84.6 | 0 | 19.27 |
| 1 | 35.9 | 0 | 22.84 |

高 overlap 下 m=0.4 报告 50/50 在 100 步内达标，比 m=1 遗忘少约 15.6%。shuffled-A 保护错对象的遗忘为 24.54。支持“专家身份可以包含有用信息”的构造性例子。

目标边界：若只在 100 步约束内最小化遗忘，固定 m=0.4 在两种状态都可为已测试候选最优，因此尚未证明需要 overlap 才能选到最优动作。加入“遗忘相同选更少计算”后，状态策略的决策收益才明确。已建议主/次共享角色交换检验动作排序反转。

在标量线性、平方损失、固定 gate、相同 B 输出终点等假设下，解析参考为：

$$
\frac{F_{\rm high}(m)}{F_{\rm high}(1)}
=\left(\frac{0.68m}{0.64m+0.04}\right)^2.
$$

m=0.4 预测约 15.56% 降幅。若错把 0.4 施加在非共享次专家上，预测
22.84 × [0.68/(0.64+0.04×0.4)]² 约为 24.54。这是对报告数字的条件解释，不是已核实代码机制；可用 gate 比例变化检验。

### 4.2 离线动作预测与闭环结果的落差

另一用户报告的固定-router toy 有 1260 个状态，动作缩放 protected expert 的 Adam 位移，五档动作；每分支固定动作续跑至目标或剩余预算。目标 B loss 小于 0.01，预算 100。

报告的 oracle 动作频数按 {0,.25,.5,.75,1} 为 {591,366,147,41,115}。近似匹配 t、B loss、路由和预算的两个状态偏好 0 与 .25；提示历史路径可能重要。

| 输入 | 动作命中率 | 动作 MAE |
|---|---:|---:|
| Progress | 55.9% | 0.167 |
| Progress＋上一动作 | 55.6% | 0.167 |
| Feedback | 66.3% | 0.105 |

| 闭环策略 | B 达标率 | 最终 A loss | 达标步数 |
|---|---:|---:|---:|
| 固定 m=.5 | 100% | 1.205 | 61.8 |
| Progress | 100% | 1.066 | 69.3 |
| Feedback | 100% | 1.148 | 68.1 |
| 分支参考策略 | 100% | 0.623 | 97.9 |

离线预测改善没有转化为闭环胜出。0.623 是带分支查询成本的经验参考，不是理论最优或严格上界；尚需知道动作选择使用 A-memory 还是 A-test。反馈特征组同时增加了 B 变化量等信息，不能仅凭上述表格认定增益来自旧知识反馈。

近似匹配状态、分类性能和非恒定动作频数都不是条件互信息大于零的形式证明，也不排除最优集合重叠、任务差异和高代价少数错误。后续应使用实际终点代价、补齐的 Progress、根历史隔离及真实 rollout。

## 5. 工程内证据应怎样引用

完整 v1–v7 结论见 [研究总览](research.md) 及各冻结报告，不将上述用户 toy 数字混入。

- v1/v2 没有验证学习型反馈优势；v2 选中初始化模型尤其不能称为“学到策略”。
- v3/v4 的分支与状态聚合未给出稳定反馈改善，v4 直接冻结已能全部达标。
- v5 表明特定冲突形态不是必要前提，但计划选择没有稳定超过强时间/冻结对照。
- v6 验证闭环选模的重要性，不等于学习能力问题已全部解决。
- v7 段内反馈有初步信号，达标率非劣效与多重比较后稳定性尚未完成；原始 A 与所有过去知识保留不同。

## 6. 未获证实的主张

当前不能写“RL 已优于强规则”“GRPO 比 PPO 更省计算”“路由 usage 足以预测遗忘”“逐 expert 必优于两组”“长期任务必需 RL”“当前已在真实 MoE 验证”。

也不应写“之前负结果否定这个方向”。它们约束的是具体环境、动作、观测、训练和评价组合。文献提供可复用方法，但训练分布、可观测性、控制能力、泛化与成本仍是主要研究问题。

## 8. 本日后续讨论：规模、联合控制与分层实验

用户确认更新总体方案与主线。以下整合“大规模 MoE 联合决策”和“三层实验平台”两轮意见，状态为方案更新，不是新结果或启动全部训练。

**采纳到当前主线：**

- 多层 MoE 允许专家之间、层之间的条件依赖；使用共享局部编码、层摘要、全局协调，不为每个 expert 维护独立 agent。
- 结构化探索采用层/组模式与稀疏专家修正候选；倍率概率、对象选择概率及确定性解码器的实际训练路径必须说清。
- 输入补覆盖量、缺失和时效等可靠性摘要；有限 memory 未观察到的 expert 不能直接视为低风险。
- 标准视觉任务作为近期完整方法入口，语言 LoRA expert 与原生 MoE 分层验证。La-MAML、CP-MoE 配方提供底座，改造模型与停止规则后必须重跑统一协议基线。
- 对照加入局部规则、局部学习器、协调规则、协调学习器，区分协调能力与学习的贡献。GRPO 保留 PPO 和非 RL 参照。
- 全部历史评价保存固定任务基准及表现矩阵；明确每段完成后的记忆更新，避免只保护原始 A 或不断重置基准掩盖累计遗忘。

**对外部建议补充的限制：**

1. 上万 expert 是规模背景，不是规则必败的证据。容量增加可能减少冲突，需控制容量压力、激活计算和任务难度。
2. “先视觉、再语言、再原生”是证据层次。若主张原生专家可塑性，不能永久以 LoRA 结果代替；不同平台重新训练也不是同一控制器冻结迁移。
3. CIFAR 全类别元训练后换顺序属于历史泛化；类不相交拆分与完整 20×5 最终序列不能同时默认成立。语言任务按来源处理近重复。
4. 目标 loss 或生成规则在开发阶段固定；保留初始达标、未达标和终点差异。控制器以目标为输入时，一个目标的轨迹不能充作其他目标下的运行。
5. 小模型 200×4×4×200=640,000 次 learner 更新是单配置单 seed 上限；两学习率五 seeds 达到 6,400,000 次，仍不含基线/观测。800 次起点抽取不是 800 个独立历史。
6. CP-MoE 的“8 experts”是模块配置，逐 expert 控制前必须定义跨层/投影绑定；原生模型另测训练与复制成本。

具体数值、数据划分、记忆分配、奖励与硬件预算仍待校准。完整规划保存在 [总体方案](mainline-plan.md)，本次没有改变 v1–v7 源码、冻结协议和结果。
