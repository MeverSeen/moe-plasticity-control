# 研究范围与证据

## 核心问题

在固定 MoE 容量、记忆和计算预算下，利用路由共享结构确定保护对象后，根据实时学习与遗忘反馈调节保护倍率，能否优于最佳固定倍率、进度调度和简单反馈规则？

## 当前可实现的控制器

v2–v6 先根据旧、新任务路由统计确定固定保护组。控制器每 5 步从 `{0, 0.25, 0.5, 0.75, 1}` 选倍率，缩放保护组的 Adam 参数位移；其余专家正常更新。旧样本分为回放记忆与在线监测记忆，独立评估样本不作为在线输入。

共同输入包含初始路由与能力摘要、新任务 loss 及变化、剩余预算、训练步数和上次动作。Feedback 额外读取当前旧知识退化及近期旧损失变化；Progress 屏蔽这些输入。具体输入定义和预算见各版本 README 与锁定协议。

v7 把后续学习扩展为连续三个新输入域，跨段保留参数、Adam 矩和全局更新计数；共同初始 A loss 与 A 遗忘基准始终固定。分别比较每段重选一次、每 5 步重选一次两种频率。Progress 仍使用新任务反馈，所消融的是当前旧知识反馈。原始 A 记忆固定，前面 B 的最终保留另外评估。

## 已有证据及边界

- v1：学习型专家控制没有胜过重要性规则。
- v2：两种 PPO 都在开发集选中初始化检查点，不能把最终冻结行为称为学到的反馈策略。
- v3：对同一完整状态、相同未来批次进行动作分支；干预后使用相同 continuation，再到达终点。独立未来复测用于检验事后动作排序的可重复性。本轮两项主要比较都未验证反馈优势。
- v4：在同一建模和标注方法下完成两轮学习器状态聚合、等查询数非学习策略状态对照与后续策略诊断。80 个新测试历史上各组均全部达标，但主要反馈增益区间跨零，聚合未优于等查询数对照。固定冻结保护组已全部达标，当前环境未形成足够明确的动态控制收益证据。
- v5：24 个新校准历史扫描六个目标/预算设置和 17 个固定/时间/进度计划，锁定后在 64 个新历史确认。特权按历史选固定倍率在独立未来批次流上优于全局 `m=0.25`，但特权计划选择未稳定超过锁定的时间调度。事后检查中，五档倍率均可行的 59 个历史上，特权选择也没有优于直接 `m=0`。完整结果见 [解读](../experiments/v5_calibration/结果解读.md)。
- v6：冻结环境后，32 状态拟合和明确可学习的辅助反馈正对照通过基本能力检查。同一训练损失、同一候选池，改用开发集真实闭环筛选后，96 个新历史的遗忘由 0.007971 降至 0.006028（约 −24.4%），达标率相同。改用 raw MSE 未单独显示稳定收益；主要 Feedback−Progress 差为 −0.000101，95% CI [−0.000376, 0.000181]，仍跨零。强时间策略也未被击败。详见 [学习诊断解读](../experiments/v6_learning_diagnostics/结果解读.md)。

- v7：64 个新测试历史、3 个初始化中，段内 Feedback 相对 Progress 在共同成功的 56 个根历史上 A 遗忘由 0.007195 降至 0.006205，约 −13.8%，名义 95% CI [−0.001963,−0.000071]。达标率为 89.06% vs 89.58%，尚未证明非劣效；两项主要比较的 Bonferroni 敏感性区间跨零。段间 Feedback 达标率更高、遗忘也更大。原始 A 保留与全部 B 保留不同，最后全部 B 仍达标仅约 48%–49%。详见 [连续学习解读](../experiments/v7_sequence_feedback/结果解读.md)。

对话中另有用户报告的最小系统正结果；其代码与原始数据不在本工程中，不能视为本仓库已经复现。这里的七轮 MoE 实验都是固定几何 router、非线性合成回归，不是真实 learned router；v6 辅助正对照是另外的监督映射任务。

## 后续决策

1. 后续以开发集真实闭环表现筛选控制器，并单列其额外离线成本。v6 已验证这会影响独立测试结果，不能仅凭分支评价判断训练是否有效；也不能据此声称所有学习瓶颈已排除。
2. 继续在强进度/时间基线上区分可用观测的信息价值与学习方法的能力。v7/v8的18维状态是否能辨识动作差异、教师是否匹配部署都仍开放；不能把特权参考的收益直接归因于实时反馈。
3. 比较不同 continuation 或规划长度之前，统一当前干预窗口、终点目标、预算和可用信息。仍不要求“低倍率失败、高倍率遗忘大”这一特定冲突形态，见 [校准目标说明](calibration-objective-revision.md)。存在长期收益不自动证明必须使用 RL。
4. v7 已扩展到三个连续新输入域，初步段内反馈信号应先在新历史复测，预先定义达标率非劣效界限。若要归因于学习长度，同轮比较 K=1/2/3 并明确预算与难度，而非跨版本推断。区分原始 A 保留与所有已学任务保留；真实 learned router 仍暂缓。

所有新实验写入新的输出目录并使用未查看的最终测试历史。原始版本冻结，避免重构改变已有证据。

真实 MoE 阶段的历史/当前路由、门控权重与动态保护对象问题已记录于 [后续待办](future-real-moe-routing.md)，当前最小实验暂不改动。

## v8：动作分配与真正PPO的匹配检验

v8保持18维输入、每5步决策、连续三段Adam与固定A记忆，扩展为(m_P,m_U)的15档动作；旧五档为m_U=1列。监督与PPO均比较5/15动作及Progress/Feedback，保留epoch0、随机actor、蒸馏warm与末轮PPO对照。PPO使用自己访问的完整连续轨迹，γ=1的A监测遗忘差奖励与终端任意B失败cost，双critic和Lagrangian近似约束。

534个训练状态中227个有新增动作的经验分支改善，但64个未见历史、3初始化的四组15动作闭环控制器均比匹配5动作遗忘更多，12项校正敏感性区间支持该方向。固定(0.25,1.5)在开发集击败所扫描调度，测试达标84.38%，保留表现优于15动作动态控制。旧知识反馈与PPO的稳定额外保留收益均未验证；PPO15 Progress相对warm的达标改善仅属局部正信号。

监督评分器6/12选中epoch0、PPO2/12选中warm，不能把初始化表现归因于学习。主要组测试达标均低于预设90%目标，最终全部B monitor保留仅42%–53%，独立test约22%–26%。本轮没有认证概率约束或完整历史知识保留。详见[v8解读](../experiments/v8_allocation_ppo/结果解读.md)。

后续应优先用新训练/开发历史诊断模型选择与泛化、固定续跑teacher和闭环目标的差异，以及PPO在可行性目标上的优化；不能根据已见测试修改动作网格或继续挑检查点。更大动作集合提供可能性，有限学习与搜索是否能提取它是另一项需要验证的问题。
