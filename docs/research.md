# 研究范围与证据

## 核心问题

在固定 MoE 容量、记忆和计算预算下，利用路由共享结构确定保护对象后，根据实时学习与遗忘反馈调节保护倍率，能否优于最佳固定倍率、进度调度和简单反馈规则？

## 当前可实现的控制器

v2/v3/v4 先根据旧、新任务路由统计确定固定保护组。控制器每 5 步从 `{0, 0.25, 0.5, 0.75, 1}` 选倍率，缩放保护组的 Adam 参数位移；其余专家正常更新。旧样本分为回放记忆与在线监测记忆，独立评估样本不作为在线输入。

共同输入包含初始路由与能力摘要、新任务 loss 及变化、剩余预算、训练步数和上次动作。Feedback 额外读取当前旧知识退化及近期旧损失变化；Progress 屏蔽这些输入。具体输入定义和预算见各版本 README 与锁定协议。

## 已有证据及边界

- v1：学习型专家控制没有胜过重要性规则。
- v2：两种 PPO 都在开发集选中初始化检查点，不能把最终冻结行为称为学到的反馈策略。
- v3：对同一完整状态、相同未来批次进行动作分支；干预后使用相同 continuation，再到达终点。独立未来复测用于检验事后动作排序的可重复性。本轮两项主要比较都未验证反馈优势。
- v4：在同一建模和标注方法下完成两轮学习器状态聚合、等查询数非学习策略状态对照与后续策略诊断。80 个新测试历史上各组均全部达标，但主要反馈增益区间跨零，聚合未优于等查询数对照。固定冻结保护组已全部达标，当前环境未形成足够明确的动态控制收益证据。
- v5：24 个新校准历史扫描六个目标/预算设置和 17 个固定/时间/进度计划，锁定后在 64 个新历史确认。特权按历史选固定倍率在独立未来批次流上优于全局 `m=0.25`，但特权计划选择未稳定超过锁定的时间调度。事后检查中，五档倍率均可行的 59 个历史上，特权选择也没有优于直接 `m=0`。完整结果见 [解读](../experiments/v5_calibration/结果解读.md)。

对话中另有用户报告的最小系统正结果；其代码与原始数据不在本工程中，不能视为本仓库已经复现。这里的五轮实验都是固定几何 router、非线性合成回归，不是真实 learned router。

## 后续决策

1. v5 已完成不限定冲突形态的校准。后续先检验在线可用信息能否复现特权固定选择的收益，并与静态条件选择、充分校准的时间/进度规则比较；不能把更强信息参考值的收益直接归因于动态反馈。完整修正见 [校准目标说明](calibration-objective-revision.md)。
2. 在策略自己访问的状态上评估分布变化；监督控制比较应使用充分提供进度信息的基线，并关注达标率与决策代价而非仅动作 MAE。
3. 比较不同 continuation 或规划长度之前，统一当前干预窗口、终点目标、预算和可用信息。存在长期收益不自动证明必须使用 RL。
4. 只有机制与闭环增益成立后，再扩展到 learned router、更多专家及多个连续任务。

所有新实验写入新的输出目录并使用未查看的最终测试历史。原始版本冻结，避免重构改变已有证据。

真实 MoE 阶段的历史/当前路由、门控权重与动态保护对象问题已记录于 [后续待办](future-real-moe-routing.md)，当前最小实验暂不改动。
