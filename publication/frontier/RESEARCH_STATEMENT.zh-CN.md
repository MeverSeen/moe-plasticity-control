# MoE 可塑性控制：Frontier 岗研究陈述（草稿）

## 核心问题
在固定模型容量、有限记忆与更新预算下，能否将 MoE 持续学习中的专家参数更新视为一个**状态反馈控制**问题：根据当前新任务学习进度、历史知识退化和专家路由信息，动态分配更新强度，在**相当的新任务学习效果与成本**下，减少旧知识遗忘？

更重要的不是“RL 是否能改变动作”，而是三个层级：**哪些状态真的需要不同动作？历史知识反馈是否提供 Progress 之外的信息？在同样信息与动作空间下，学习控制律是否优于充分调优的固定/时序规则？**

## 方法
构建完整 learner / Adam / 有界记忆可克隆的配对分支环境；决策作用于实际专家参数位移，而非简单修改梯度。v8/v11 有两层、每层八个专家，可选倍率 0 / 0.5 / 1。比较局部与协调共享 GRPO 控制器、固定倍率、基于路由的启发式规则。区别记录在线达标、独立开发集达标、全部历史遗忘、样本前向与物理学习器更新数。

**边界：**小型 CIFAR-100 图像 MoE 的 router 由原始图像固定随机投影得到，任务 ID 可见，CNN 前端和任务头持续更新。倍率 0 仍推进 Adam 动量。因此不是语言预训练 MoE 的有效性验证。

## 核心证据
- **v7：**连续三段合成学习，段内 Feedback 在 56 个共同成功根历史上，相比 Progress 的原始任务 A 遗忘从 0.007195 降到 0.006205（约 13.8%）。但达标率略低，非劣效未证明，Bonferroni 敏感性区间跨零；此前学会的 B 任务最终未必保留。
- **v9：**固定每后续任务 80 次更新，全量 expert 位移的训练/开发 CE 是 0.478 / 2.093，零位移为 1.005 / 1.226。提示应先排查泛化与更新尺度，不可推断“expert 不需要更新”。
- **v11：**GRPO 延长至 48 轮后，策略概率与部署动作发生变化；但协调控制器在两个策略种子、24/48 轮、四个开发根上的贪心动作与固定零位移完全一致，平均旧任务正遗忘 F 均为 0.001300。两者均在线整序列 4/4 达标，但独立开发集最终所有任务达标只有 2/4。**证明了策略会改变，未证明状态依赖的协调收益。** 344 条轨迹只有 4 个历史根，不是独立测试结果。

## 研究判断和下一步
下一步**不应直接增加 RL 算力**。先从同一完整学习状态配对分支，测量不同专家动作在“新任务改善—全部历史退化—实际开销”下的价值；与最优固定倍率、时序规则、无状态的可学习动作分布比较。若不存在跨状态可复测的动作价值差异，应停止扩大控制器；只有发现足够的状态依赖 oracle gap 后，才比较 Progress 与 Feedback 输入、手工控制律与学习控制律，并在新历史与类别池中独立确认。
